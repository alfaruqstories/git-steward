git-steward
GitHub →

Track all your local work in one place.

One scan shows every dirty repo, stash, and ahead commit on your machine. Nothing leaves your machine.

git-steward scan --dashboard
# scanning 3 roots under ~/Code …

✓ project-alpha main · clean
~ project-beta feat/auth · 2 dirty · 1 ahead
✓ project-gamma main · 3 stashes

── 3 repos · 1 dirty · 0 blocked ──
dashboard → ~/.local/state/git-steward/dashboard.html
$ pip install git-steward
